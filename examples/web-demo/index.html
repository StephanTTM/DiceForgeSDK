DiceForge web demo

The headless core resolves every outcome first; the presenter only animates the already-resolved record. Seeded rolls advance a reproducible sequence — re-enter the seed to replay it from the start.

The DiceForge set covers every shape plus a two-faced coin, and is generated by tools/blender. 3D needs a theme to draw with — with none selected the presenter falls back to labelled tiles. See assets/LICENSES.md for provenance.

Notation takes any face count (4d3, 1d30) and custom dice defined by their faces: this demo registers a Fate die, so 4d{fate} rolls faces worth −1, 0 and +1 that read as symbols. A custom die has no honest 3D model, so it always lands as tiles. Dice can also explode and reroll: 4d6! adds a die for every 6, and 4d6r1kh3 rerolls 1s before keeping the best three.
